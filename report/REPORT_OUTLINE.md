# Report outline (15 pages max, not counting refs/appendix)

Just a checklist so we don't forget a section. Fill in notes here as we go, then someone writes it up properly in Word.

1. Cover page - course name, assignment title, group name, our names + IDs
2. Introduction - what the 3 problems are, why we picked these algorithms, what language/tools we used
3. Problem 1 (Greedy) - description, strategy explanation, I/O design, code snippets, screenshots, strengths/limitations
4. Problem 2 (DP/Backtracking) - same breakdown as above
5. Problem 3 (Heuristic) - same breakdown as above
6. Testing and validation - test cases, expected vs actual output, how we checked correctness
7. Challenges and solutions - what went wrong, how we fixed it
8. AI usage declaration - what we used, what for, how we checked it was correct
9. Conclusion
10. References

Individual reflections go in separately, not in this report.
